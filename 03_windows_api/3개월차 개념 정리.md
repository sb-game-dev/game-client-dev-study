<details>
  <summary>wWinMain</summary>

- c++의 main()함수의 역할
- windows GUI 프로그램의 시작점

> 선언부
```cpp
int APIENTRY wWinMain(_In_ HINSTANCE hInstance,          // 현재 실핸중인 프로그램의 인스턴스 핸들
                     _In_opt_ HINSTANCE hPrevInstance,   // 이 프로그램이 시작되기 전에 이전 프로그램의 인스턴스를 받는 곳(없으면 NULL)
                     _In_ LPWSTR    lpCmdLine,           // LP(포인터) W(유니코드) STR(문자열)
                     _In_ int       nCmdShow)            // 창 생성 옵션(SW_SHOW, SW_MINIMIZE, SW_MAXIMIZE)

```

> 몸체
```cpp
// 창 제목, 클래스 이름 문자열을 가져옴
LoadStringW(hInstance, IDS_APP_TITLE, szTitle, MAX_LOADSTRING);
LoadStringW(hInstance, IDC_DEFAULTWINDW, szWindowClass, MAX_LOADSTRING);

// 창 클래스 등록 MyRegisterClass() 전역 함수 호출
MyRegisterClass(hInstance);

// 실제 창 생성 InitInstance() 전역 함수 호출 -> 내부에서 CreateWindow 통해 창 생성
if (!InitInstance (hInstance, nCmdShow))
{
    return FALSE;
}

HACCEL hAccelTable = LoadAccelerators(hInstance, MAKEINTRESOURCE(IDC_DEFAULTWINDW));

MSG msg;

// 메시지 루프 진입해서 여기서 프로그램이 작동하는 중
while (GetMessage(&msg, nullptr, 0, 0))
{
    if (!TranslateAccelerator(msg.hwnd, hAccelTable, &msg))
    {
        TranslateMessage(&msg);
        DispatchMessage(&msg);
    }
}

return (int) msg.wParam;


```

```cpp
HWND hWnd = CreateWindow( //HWND 창 핸들을의미
```

<details>
    <summary>메시지 루프</summary>

- windows 프로그램은 **이벤트 기반**으로 동작
- 사용자가 키 입력('A' 입력) -> windows가 메시지 생성(WM_KEYDOWN) -> 메시지 큐에 넣음

> GetMessage

- 메시지 큐에서 하나 꺼냄`GetMessage(&msg,nullptr,0,0)`
- 꺼낸 결과를 `MSG msg에 저장`
```cpp
WM_KEYDOWN
WM_MOUSEMOVE
WM_PAINT
```

> MSG 구조체
```cpp
struct MSG
{
    HWND hwnd;
    UNIT message;
    WPARAM wParam;
    LPARAM lParam;
};
```
- 시작시 `msg.message = WM_NULL;` 넣어서 쓰레기값이 들어가는 것을 방지
- 만약 'A'키 입력시
```cpp
message = WM_KEYDOWN
wParam = 'A'
```
> TranslateMessage

- 키보드 입력 메시지를 문자 메시지로 변환
```cpp
TranslateMessage(&msg);
```
- WM_KEYDEOWN -> WM_CHAR로 변환
- 보통 항상 넣음

> DispatchMessage


```cpp
DispatchMessage(&msg);
```
- **메시지를 실제 처리 함수(WndProc)로 보내라**를 수행함
- 내부적으로 아래와 같은 느낌으로 WndProc를 호출
```
WndProc(
    msg.hwnd,
    msg.message,
    msg.wParam,
    msg.lParam
);
```
</details>

### 2일차 (260514) 총알 발사

1. 메인 함수에서 while문 조건 수정
GetMessage(&msg, nullptr, 0, 0) -> PeekMessage(&msg, nullptr, 0, 0, PM_REMOVE) 

- PeekMessage : 메세지 큐에 메세지가 없는 경우 거짓을 반환
- PM_REMOVE   : 메세지 큐에 메세지가 있을 경우, 가지고 오면서 큐로부터 메세지를 삭제
- PM_NOREMOVE : 메세지 큐에 메세지 유무 상태만 파악, 만약 큐에 있는 메세지를 가져오려면 개별적으로 GetMessage 함수를 다시 호출해야 함

2. while(true)로 조건 수정하고 while문에서 if(PeekMessage(*msg, nullptr, 0, 0, PM_REMOVE)) else 사용

```cpp
if(PeekMessage(*msg, nullptr, 0, 0, PM_REMOVE))
{
    // 키보드 입력이 있는 경우 실행할 코드 -> 입력 처리
}
```
