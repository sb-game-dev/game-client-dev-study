## 5개월차 개념 정리

### 1일차 디바이스 초기화

<details>
  <summary>디바이스 초기화 순서</summary>

> 최종 솔루션 구성

```cpp
- Client
    - Bin
    - Code
    - Header
    - Include
- Engine
    - Bin
    - Code
    - Header
    - Include
- Reference
    - Header
    - Library
- Base
```

> 생성 과정

1. 빈 솔루션 생성
2. 솔루션 → 추가 → 새 솔루션 폴더 → 00. Client | 01. Engine | 02. Base 각각 생성
3. 솔루션의 저장 폴더에 Base | Reference 폴더 각각 생성 → Reference 폴더에서 Header, Library 폴더 생성
4. 00. Client 폴더에서 추가 → 새 프로젝트 → Window 데스크탑 마법사 → 프로젝트 이름은 Client로 → 데스크톱 애플리케이션과 미리 컴파일된 헤더 설정
5. Client 프로젝트를 솔루션에서 제거 → 솔루션의 저장 폴더에서 Client 폴더로 → Client 폴더에 Bin | Code | Header | Include 폴더를 각각 생성
6. Client 폴더에서 기존에 있던 파일들은 Include 폴더로 이동
7. 00. Client 솔루션 폴더에서 추가 → 기존 프로젝트 → Client/Include/.vcxproj 선택
8. Client 프로젝트 경로 설정 (모든 구성으로 설정)
    1. 일반 → 출력 디렉터리 → ../Bin\
    2. VC++ 디렉터리 →
        1. 포함 디렉터리 → $(DXSDK_DIR)Include
        2. 라이브러리 디렉터리 → $(DXSDK_DIR)Lib/x64
    3. C/C++ → 일반 → 추가 포함 디렉터리 → 
        1. ../Header;
        2. ../../Base
        3. ../../Reference/Header
    4. 링커 → 일반 → 추가 라이브러리 디렉터리 → ../../Reference/Library
    5. 링커 → 입력 → 추가 종속성 → 
        1. d3d9.lib
        2. d3dx9.lib
        3. dxguid.lib
        4. dinput8.lib
        5. Engine.lib
9. 01. Engine 폴더에서 추가 → 새 프로젝트 → Window 데스크탑 마법사 → 프로젝트 이름은 Engine으로 → 동적 연결 라이브러리와 빈 프로젝트 설정
10. Engine 프로젝트를 솔루션에서 제거 → 솔루션의 저장 폴더에서 Engine 폴더로 → Engine 폴더에 Bin | Code | Header | Include 폴더를 각각 생성
11. Engine 폴더에서 기존에 있던 파일들은 Include 폴더로 이동
12. 01. Engine 솔루션 폴더에서 추가 → 기존 프로젝트 → Engine/Include/.vcxproj 선택
13. Engine 프로젝트 경로 설정 (모든 구성으로 설정)
    1. 일반 → 출력 디렉터리 → ../Bin\
    2. VC++ 디렉터리 →
        1. 포함 디렉터리 → $(DXSDK_DIR)Include
        2. 라이브러리 디렉터리 → $(DXSDK_DIR)Lib/x64
    3. 코드가 하나도 없으면 C/C++ 탭이 생기지 않으므로 아무 클래스나 만들기
    4. C/C++ 일반 → 추가 포함 디렉터리 →
        1. ../Header;
        2. ../../Base
    5. 방금 생성한 클래스 삭제
    6. 링커 → 입력 → 추가 종속성 → 
        1. d3d9.lib
        2. d3dx9.lib
        3. dxguid.lib
        4. dinput8.lib
14. 테스트를 위해 ‘4일차-Device 장치 초기화’ 수업 코드에서 다음 코드들을 복붙한다.
    1. Base
    2. Client/Code
    3. Client/Header
    4. Client/Include
        1. pch.h
        2. Client.cpp
    5. Engine/Code
    6. Engine/Header
15. 복붙한 파일들을 각 프로젝트에서 추가 → 기존 항목에서 선택한다.
16. Engine 프로젝트를 먼저 빌드하여 Engine/Bin에 Engine.dll, Engine.lib 파일이 추출되는 것을 확인한다.
17. Engine에서 변경 사항이 있을 경우 항상 해야하는 행동
    1. Reference/Header에 Engine의 바뀐 헤더 파일을 복사
    2. Reference/Library에 Engine.lib를 복사
    3. Client/Bin에 Engine.dll을 복사
18. 이제 Client 프로젝트를 빌드하고, 문제가 없다면 실행할 수 있다.
</details>
