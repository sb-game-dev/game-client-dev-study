# 덕코프 모작

<details>
  <summary>제작할 컨텐츠</summary>

> 조작

[ ] w,a,s,d로 이동  
[ ] space로 구르기  
[ ] L-Shift로 달리기  
[ ] 마우스 방향으로 플레이어의 Look 설정  
[ ] 마우스를 맵 구조물에 가져다대면 블러처리  
[ ] 조준 시 카메라 위치 조정  
[ ] 조준 시 이동속도 조정  
[ ] 조준 시 스코프 UI 변경  

> 플레이어 시야

[ ] 원 + 부채꼴 범위로 시야를 설정  
[ ] 부채꼴 범위의 시야 부분은 구조물에 가려서 짤리는 부분이 생기는 경우도 있음  
[ ] 시야 밖의 몬스터들은 보이지 않지만 근처에 오거나 소리를 내면 반달 모양으로 표시됨(헤드셋 아이템)  
[ ] 벽에 가려진 경우 실루엣이 보임  
[ ] J-Lab의 경우 조명 + 적외선 카메라를 장착해야 보이는 경우가 있음  

> UI

[ ] 데미지  
[ ] 인벤토리  
[ ] 마우스 호버시 아이템의 설명 + 상호작용키  
[ ] HP  
[ ] 배고픔, 목마름  
[ ] 총1 + 총알 종류 + 총알 수(1) / 총2 + 총알 종류 + 총알 수(2)  
[ ] 근접무기(V)  
[ ] 소비아이템(3 ~ 8)  
[ ] 게임 시간 낮(6:00 ~ 17:59), 해질녁(18:00 ~ 21:59), 밤(22:00 ~ 5:59)   
[ ] 날씨(맑음, 흐림, 비)  
[ ] 달리기 체력  
[ ] 스코프UI + 재장전UI  

> 씬 종류

[ ] 기지  
[ ] 첫 번째 스테이지(제로존)  
[ ] 두 번째 스테이지(J-Lab)  

> 게임 시스템

[ ] 재장전시 모든 정신집중(소비아이템 사용, 재장전 등) 취소  
[ ] 출혈  
[ ] 죽으면 펫 인벤토리 + 근접무기를 제외한 모든 아이템이 사라진다  
[ ] 철수 기능  
[ ] 게임 시간(밤에는 거미가 나옴)  
[ ] 침대에서 자면 밤을 빠르게 넘길 수 있음  
[ ] 폭풍이 오면 가만히 있어도 체력이 닳고 폭풍이 오는 시간이 있음  
[ ] 방어구의 내구도  
[ ] 중량 시스템  
[ ] 인벤토리를 마우스 휠로 조작할 수 있음  
[ ] 몬스터 처치시 몬스터의 아이템(전리품)을 파밍할 수 있고 처음 보는 전리품의 경우 첫 번째 슬롯을 제외한 나머지 슬롯은 천천히 보여짐  
[ ] 전리품을 들고 이동할 수 있음  
[ ] 구르기는 자체적으로 쿨타임 1초가 있음  
[ ] 헤드샷 판정  
[ ] 총의 반동  
[ ] 미니맵  
[ ] 캐릭터 변경(광전사, 끌차 등등)  
[ ] 열쇠  
[ ] 첫 번째 스테이지(제로존)의 경우 물에는 못들어감  
[ ] 기지에 구조물을 설치할 수 있음  
[ ] 기지의 보관함  
[ ] 기지의 상점  
[ ] 씬 전환시 작은 원이 확대되며 전체 화면이 보임  

</details>

  <summary>리소스 파일 구조</summary>

```cpp
Resource
├─ Character
│  ├──Boss
│  ├──FootballDuo_1
│  └──FootballDuo_2
├─ Cutomize
│  ├──Beak       //부리
│  ├──Crest      //벼슬
│  ├──Default    
│  ├──Eye        
│  ├──Hair      
│  └──Hand       
├─ Item
│  ├──Attach      //부착물
│  ├──Bullet      //총알
│  ├──Consumable  //소비 아이템
│  ├──Equipment   //장착 아이템
│  ├──Material    //제작 재료
│  └──Valuable    //판매용 아이템
├─ Prop
│  ├──Barrier      //이동은 막지만 총알은 통과할 수 없는 것들
│  ├──Debris       //아무 기능 없는 순수 장식
│  ├──Lootable     //인벤토리를 가지고 F키 상호작용이 붙는 것들
│  ├──Nature       //자연 장식들
│  ├──Structure    //이동과 총알을 모두 막는 고정 구조물
│  └──Vehicle      //덩치크고 엄폐물로 쓰이는 것들
└─ Terrain
```
