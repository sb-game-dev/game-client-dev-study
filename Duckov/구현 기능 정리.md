# 덕코프 구현 기능 정리


### 인벤토리
<details>
  <summary> 0. 개요 </summary>

- 덕코프의 인벤토리는 슬롯 리소스를 제공하지 않는다.
- 모든 격자칸은 셰이더를 통해 그려야 한다.
- 각 칸들을 그릴 때 마다 Draw콜을 하면 비용이 비싸기 때문에 인스턴싱을 활용하여 슬롯을 그린다.

</details>


<details>
  <summary> 1. 슬롯 정보 </summary>

> 슬롯 한 칸의 정보

```
- 지역   : 장비창, 가방, 밖
- 인덱스 : 특정 지역의 몇 번째 칸인지 -> ex) 가방의 7번 인덱스 -> 가방 지역의 2행 3열 칸
struct SLOT_POS // 칸 하나를 {영역, 번호} 쌍으로 설정. ex) {EQUIP, 2} -> 장비 3번째 칸 == 근접무기
{
	INVEN_AREA eArea = INVEN_AREA::END;
	int32_t    iIndex = -1;
	bool operator==(const SLOT_POS& r) const 
	{ 
		return eArea == r.eArea && iIndex == r.iIndex; 
	}
};

- float4_t Rect  : Left, Top, Width, Height
- float4_t Color : RGBA
- float4_t Shape : 모서리 반지름, 테두리 두께, 도형 or 아이콘, 아이콘 번호
- float4_t vUV   : 아이콘 UV 거의 대부분 (0,0,1,1)로 설정

typedef struct tagVtxUIInstance
{
	float4_t    vRect;      // left, top, width, height (화면 픽셀, 좌상단 원점)
	float4_t    vColor;     // RGBA
	float4_t    vShape;     // x: 모서리 반지름, y: 테두리 두께(0=채움), z: 0 도형 / 1 아이콘, w: 아이콘 번호
	float4_t    vUV;        // 아이콘 UV (0,0,1,1)

	static constexpr uint32_t iNumElements = 7;
	static constexpr D3D11_INPUT_ELEMENT_DESC Elements[iNumElements] =
	{
		{ "POSITION", 0, DXGI_FORMAT_R32G32B32_FLOAT,    0,  0, D3D11_INPUT_PER_VERTEX_DATA,   0 },
		{ "NORMAL",   0, DXGI_FORMAT_R32G32B32_FLOAT,    0, 12, D3D11_INPUT_PER_VERTEX_DATA,   0 },
		{ "TEXCOORD", 0, DXGI_FORMAT_R32G32_FLOAT,       0, 24, D3D11_INPUT_PER_VERTEX_DATA,   0 },
		{ "UIRECT",   0, DXGI_FORMAT_R32G32B32A32_FLOAT, 1,  0, D3D11_INPUT_PER_INSTANCE_DATA, 1 },
		{ "UICOLOR",  0, DXGI_FORMAT_R32G32B32A32_FLOAT, 1, 16, D3D11_INPUT_PER_INSTANCE_DATA, 1 },
		{ "UISHAPE",  0, DXGI_FORMAT_R32G32B32A32_FLOAT, 1, 32, D3D11_INPUT_PER_INSTANCE_DATA, 1 },
		{ "UIUV",     0, DXGI_FORMAT_R32G32B32A32_FLOAT, 1, 48, D3D11_INPUT_PER_INSTANCE_DATA, 1 },
	};
}VTXUI_INSTANCE;

```

<details>
  <summary> 2. 셰이더 </summary>

> 전역변수 및 상수버퍼 설정

- 인스턴싱으로 그리기 때문에 상수버퍼 b0은 필요 없다.
- 텍스처 배열을 사용하여 여러 아이콘을 텍스처 한 장으로 받는다.

```hlsl
cbuffer cbCamera : register(b1)
{
    float4x4 g_matView;
    float4x4 g_matProj;
    float3 g_vEye;
    float g_Pad;
};

static const float2 g_vWinSize = float2(1280.f, 720.f); 

Texture2DArray g_IconArray : register(t0);
SamplerState g_Sampler : register(s0);
```

> VS_IN

- 기본적인 텍스처를 사용하는 버텍스 버퍼 3개(Position,Normal, TexCoord)와 인스턴스 정보 4개로 구성되어있다.

```hlsl
struct VS_IN
{
    float3 vPosition : POSITION; 
    float3 vNormal : NORMAL;
    float2 vTexCoord : TEXCOORD0;
    float4 vRect : UIRECT;
    float4 vColor : UICOLOR;
    float4 vShape : UISHAPE;
    float4 vUV : UIUV;
};
```

> VS_OUT

- float2 vLocal : 원점이 사각형 중심이고 크기만 곱해진 로컬 스페이스의 좌표, 둥근 테두리 밖인지 확인할 때 사용
- nointerpolation : 레스터라이즈 단계 에서 보간하지 말라는 키워드. 보간하지 않으면 모든 픽셀들의 값은 삼각형의 첫 번째 정점의 값으로 설정.

struct VS_OUT
{
    float4 vPosition : SV_POSITION;
    float2 vLocal : LOCAL; 
    float2 vTexCoord : TEXCOORD0;
    nointerpolation float4 vColor : COLOR;
    nointerpolation float4 vShape : SHAPE;
    nointerpolation float2 vSize : SIZE;
};
