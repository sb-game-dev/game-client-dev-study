# 모델 구조 점검 질문 (애니메이션 들어가기 전)

> 답은 직접 코드를 보면서 채워 넣기. 막히는 질문 = 다시 봐야 할 부분.

## 1. 로딩 (.fbx)
1. `ReadFile`에 넘기는 플래그(`aiProcess_...`)는 각각 무엇을 해 주나? 하나를 빼면 어떤 문제가 생기나?
2. 애님 모델과 논애님 모델의 로딩 플래그가 다르다면 왜 다른가?
3. `aiScene`은 언제까지 살아 있나? 로딩이 끝나면 Assimp 데이터가 없어도 모델이 그려지나? 그렇다면 그동안 필요한 정보는 어디로 옮겨졌나?

## 2. 메시
4. 정점 버퍼와 인덱스 버퍼에는 각각 무엇이 들어가나? 인덱스 버퍼가 없으면 무엇이 불편해지나?
5. `aiMesh`의 면(Face) 정보로 인덱스를 만들 때 왜 면 하나당 인덱스가 3개인가? 어떤 플래그가 그걸 보장하나?
6. 논애님 메시는 PreTransformMatrix를 정점에 미리 곱한다. 애님 메시는 왜 미리 곱하면 안 되나? (곱하지 않는다면 대신 어디서 적용하나?)

## 3. 머티리얼
7. 메시가 머티리얼 "포인터"가 아니라 "인덱스"를 들고 있는 이유는?
8. `aiTextureType`별로 텍스처를 배열에 담는 이유는? 셰이더에서 어떤 텍스처를 쓸지 무엇으로 고르나?
9. 텍스처 경로는 .fbx 안에 어떤 형태로 들어 있나? 실제 파일 경로는 어떻게 조립하나? 경로가 틀리면 어디서 실패하나?
10. 메시 여러 개가 같은 머티리얼을 쓰면 텍스처는 몇 번 로드되나?

## 4. 본
11. 본을 노드 트리를 재귀로 돌면서 만들 때, 왜 부모가 자식보다 먼저 배열에 들어가야 하나?
12. 본이 부모를 포인터가 아니라 "인덱스"로 들고 있는 이유는? (Clone과도 연결해서 생각해 보기)
13. `aiNode`의 mTransformation을 가져올 때 전치(Transpose)하는 이유는?
14. 메시에 정점이 하나도 붙어 있지 않은 노드도 본으로 만드나? 만든다면 왜 필요한가?
15. CombinedTransformationMatrix = 자기 Transformation × 부모 Combined. 곱하는 순서가 반대면 어떻게 되나?
16. 이름으로 본을 찾는 함수는 어디서 쓰이나? 애니메이션 채널과는 어떻게 연결될까?

## 5. 메시 ↔ 본 연결 (애니메이션 직전 핵심)
17. `aiMesh`의 `mBones`와 모델 전체의 본 배열은 같은 것인가? 무엇이 다른가?
18. 메시가 들고 있는 "본 인덱스 목록"과 정점의 BlendIndices는 각각 어떤 배열을 가리키는 인덱스인가?
19. OffsetMatrix는 무엇을 무엇으로 바꿔 주는 행렬인가? 왜 본이 아니라 메시 쪽에 저장되나?
20. 정점 하나가 본 4개까지 영향을 받는다. 가중치(BlendWeights)의 합은 얼마여야 하나? 아니면 어떻게 보이나?
21. 본 영향을 하나도 안 받는 메시가 애님 모델 안에 있다면 BlendIndices/Weights를 어떻게 채워야 하나?
22. 셰이더에 넘기는 본 행렬 배열의 최대 개수는 어디서 정해지나? 메시 하나의 본이 그 수를 넘으면?

## 6. 렌더 흐름
23. 모델 하나를 그릴 때 Draw 호출은 몇 번 일어나나? 무엇을 기준으로 나뉘나?
24. 메시마다 "셰이더에 넘기는 것 → Begin(패스) → Bind 버퍼 → Draw" 순서를 말로 설명할 수 있나?
25. 최종 본 행렬은 (Offset × Combined × PreTransform) 같은 식으로 만들어진다. 각 항이 왜 필요한가? 순서는 어떻게 되나?
26. 월드 행렬은 본 행렬과 별개로 넘어가나? 셰이더에서 정점은 어떤 순서로 변환되나?

## 7. 프로토타입 / 클론
27. Clone된 모델들이 메시, 머티리얼, 본 중에서 공유하는 것과 각자 가져야 하는 것은? 그 이유는?
28. 모든 클론이 본을 공유한 채로 애니메이션을 돌리면 화면에서 어떤 일이 생기나?
29. 공유하는 리소스의 Release는 누가 하나? 레퍼런스 카운트는 어디서 올라가나?

## 8. 최종 확인
30. 머리 본 하나가 30도 회전했을 때, 그 머리 정점이 화면에 그려지기까지 일어나는 일을 CPU 쪽부터 셰이더까지 순서대로 설명할 수 있나?
31. 애니메이션이 추가되면 지금 구조에서 "매 프레임 바뀌는 값"은 정확히 무엇 하나뿐인가? 나머지는 전부 고정인가?

> 5번 섹션(17~22)과 30·31번을 막힘없이 답할 수 있으면 애니메이션으로 넘어가도 된다.
