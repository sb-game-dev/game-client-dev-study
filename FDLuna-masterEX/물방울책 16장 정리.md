# DX11 공부 정리(물방울책) - 16장

### Chapter16. 피킹

<details> 
  <summary> 0. 피킹이란 </summary>

- 피킹이란 사용자가 마우스 커서로 3차원 물체를 찍는 것
- 마우스 커서의 2차원 화면 좌표가 주어졌을 때, 그 점으로 투영된 3차원  물체를 알아내는 것
- 그래픽 처리과정을 뒤집어서 생각해야 함. (2D 화면 -> 3D 월드 or 로컬 스페이스)

</details>

<details>
  <summary> 1. 화면에서 투영 창으로의 변환 </summary>

> 화면 픽셀 -> NDC

- NDC(-1 ~ 1) ->  화면 픽셀(0 ~ w, 0 ~ h) 로 변환할 때 공식
```
sx = (x_ndc + 1) * w/2
sy = (1 - y_ndc) * h/2
```

- 화면 픽셀(0 ~ w, 0 ~ h) -> NDC(-1 ~ 1) 로 변환할 때 공식
```
x_ndc = sx * 2/w -1
y_ndc = -sy * 2/h +1
```

> NDC -> 뷰

- 투영창이란 카메라(원점) 앞 거리 d에 놓인 가상의 창문이다.
- 투영창의 세로 길이 : 2 (-1 ~ 1)
- 투영창의 가로 길이 : 2r (-r ~ r) // r : 종횡비(w/h)
- `x_p = x_ndc * r`, `y_p = y_ndc` 
- tan(a/2) = 1/d
- 반직선의 방향벡터 : (x_p, y_p, d) -> 방향벡터이므로 d로 나누면(x_p/d , y_p/d, 1)이다.
- 방향벡터 (x_p/d , y_p/d, 1)을 ndc값으로 바꾸면 (x_ndc * r/d , y_ndc/d, 1) 이고
- r/d , 1/d 는 각각 투영행렬의 00, 11 의 값이다.

```
뷰 스페이스에서의 반직선의 방향벡터
{
    (2 * sx / w - 1) / p(0,0),
    (1 - 2 * sy / h) / p(1,1),
    1
}
```
- 이렇게 만든 뷰 공간에서의 반직선을 월드 or 로컬 스페이스로 변환을 해서 사용할 수 있다.
- 이때 반직선의 시작점인 `RayOrigin`은 카메라 `vEye`의 월드 좌표가 되고
- 반직선의 방향벡터인 `RayDir`은 뷰 -> 월드 변환행렬인 뷰행렬의 역행렬을 곱해서 얻을 수 있다.
- 로컬 스페이스로 변환하는 것은 같은 방법으로 가능하다.  

</details>

<details>
  <summary> 2. 반직선 대 메시 교차 판정  </summary>

> 반직선대 삼각형 교차 판정

- `InterSectRayTriangle(rayOrigin, rayDir, v0, v1, v2)`
  - `rayOrigin` -> 반직선의 시작 좌표
  - `rayDir` -> 반직선의 방향 벡터
  - `v0`, `v1`, `v2` -> 삼각형의 좌표
  - 반직선과 삼각형의 좌표는 같은 공간에 있어야 한다.
  - 반환값은 `bool` 타입으로 충돌했다면 `true`를 반환한다.

- 버텍스 버퍼의 모든 삼각형을 순회하며 교차하는 삼각형을 찾는다.

> 반직선 대 AABB 교차 판정

- `MeshBox.InterSect(rayOrigin,rayDir, tMin)` 함수를 사용하여 AABB와 반직선의 교차를 확인할 수 있다.
  - rayOrigin (Vector3): 반직선이 시작되는 시작점의 위치 좌표 (x, y, z).
  - rayDir (Vector3): 반직선의 방향 벡터. 계산의 정확성을 위해 크기가 1인 단위 벡터(Normalized Vector)를 사용.
  - tMin (Float): 충돌을 인정할 최소 거리 제한. 보통 0.0 또는 여유값(epsilon, 예: 0.0001)을 주어 광선 바로 앞에서 일어나는 자가 충돌(Self-intersection) 오류 방지.

</details>

<details>
  <summary> 3. 예제 : 덕코프에서의 광선 사용 </summary>

> 개요

- 덕코프에서는 레이피킹이 사용되지 않고 가까이 갔을 때 특정상호 작용 키를 누르는 방식이다.
- 다만 마우스의 위치를 바라보는 플레이어를 만들기 위해서는 반직선을 만들고 그 반직선의 방정식에 y값에 플레이어의 y값을 대입하여 마우스의 월드 좌표를 구해야 한다.  

</details>
