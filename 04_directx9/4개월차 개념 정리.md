### 1일차 벡터

<details>
  <summary>벡터</summary>

> D3DXVECTOR 자료형

- 기본적으로 float 타입의 x,y,z가 있고 연산자 오버로딩이 되어있음

> 사용 예시

- vPos    : 플레이어의 좌표 정보를 저장하기 위해 사용
- vDir    : 플레이어의 이동 방향 저장
- vLook   : 플레이어의 이동 방향 저장
- vNormal : 플레이어의 법선 벡터 저장

> 벡터의 + 연산

- 벡터의 합연산
- 주로 플레이어를 이동시킬 때 사용
- 플레이어의 좌표를 저장하는 vPos에 이동하는 방향을 저장하는 vDir을 더해서 사용
```cpp
void CPlayer::Update()
{
  m_tInfo.vPos += m_tInfo.vDir; 
}
```

> 벡터의 - 연산

- 객체를 따라가게 할 때 사용
```cpp
void CMonster::Update()
{
  m_tInfo.vDir = m_pPlayer->GetInfo()->vPos - m_tInfo.vPos;
  float fLength = sqrtf(m_tInfo.vDir.x * m_tInfo.vDir.x + m_tInfo.vDir.y * m_tInfo.vDir.y);

  // 단위 벡터로 바꿔줌
  m_tInfo.vDir.x /= fLength;
  m_tInfo.vDir.y /= fLength;
  m_tInfo.vDir.z = 0.f;

  m_tInfo.vPos += m_tInfo.vDir; 
}
```


> 벡터의 내적

- 방향을 바꿀 때 사잇각이 필요한데 이때 사용함
- 내적할 때 벡터를 단위벡터화 한 후 내적하면 결과는 cos값이 나오게 됨

<details>
  <summary>내적을 활용하여 마우스를 따라다니는 객체</summary>

> 1. 마우스 행렬 반환 함수 생성

- Define.h에 마우스 위치 벡터를 반환하는 함수 생성  
```cpp
static D3DXVECTOR3 GetMouse()
{
  POINT  pt{};
  GetCursorPos(&pt);
  ScreenToClient(g_hWnd,&pt);

  return D3DXVECTOR3((float)pt.x , (float)pt.y, 0.f);
}
```

> 2. 내적을 사용하여 각도 구하기

- 내적에 사용할 vLook 방향벡터{1.f, 0.f, 0.f} 선언
- 내적하기 전에 vLook 방향 벡터와 vDir 방향벡터를 정규화
- 정규화시 사용할 함수: D3DXVec3Normalize(결과를 저장할 벡터 주소, 단위 벡터로 저장할 벡터 주소)  
매개변수 둘 다 같은 주소 사용해도 됨
- 내적의 결과를 반환하는 함수: D3DXVec3Dot(벡터주소1, 벡터주소2)
- D3DXVec3Dot의 반환값은 라디안이고 sin값의 경우 각을 반대로 측정하는 경우도 생각해주어야 함
```cpp
void CPlayer::Update()
{
  m_tInfo.vDir = ::GetMouse() - m_tInfo.vPos;

  D3DXVec3Normalize(&m_tInfo.vDir,&m_tInfo.vDir);
  D3DXVec3Normalize(&m_tInfo.vLook,&m_tInfo.vLook);

  float fDot = D3DXVec3Dot(&m_tInfo.vDir, &m_tInfo.vLook);
  float fRadian = acosf(fDot);

  if(m_tInfo.vPos.y < GetMouse().y)
    fRadian = 2.f * D3DX_PI - fRadian;

  m_tInfo.vPos.x += cos(fRadian) * m_fSpeed;
  m_tInfo.vPos.y -= sin(fRadian) * m_fSpeed;  
}
```

### 2일차 행렬

<details>
  <summary>행렬</summary>

> 행렬을 사용하는 이유

- 객체의 여러 상태(크기, 회전, 위치)를 표현하기 위함
- 월드 변환을 위해(로컬 -> 월드)
- Local.Vtx * World.Matrix -> World.Vtx

> 자료형

- D3DXMATRIX
- 4 * 4 행렬로 이루어져있음
```cpp
_11, _12, _13, _14
_21, _22, _23, _24
_31, _32, _33, _34
_41, _42, _43, _44
```

- 크기 : _11, _22, _33 (X, Y, Z 배율)
- 위치 : _41, _42, _43 (X, Y, Z 좌표)
- X회전(y,z값을 변경): _22(cos), _23(sin), _32(-sin), _33(cos) 
- Y회전(x,z값을 변경): _11(cos), _13(-sin), _31(sin), _33(cos)
- Z회전(x,y값을 변경): _11(cos), _12(sin), _21(-sin), _22(cos)

- 정방 행렬: 행과 열의 수가 일치하는 상태, 연산의 편의성을 위해
- 항등 행렬: 항상 연산의 결과가 같은값을 가지는 형태, 기호로 I, 행렬의 초기화 상태

```cpp
1 0 0 0	->	right(dir)
0 1 0 0	->  up	(dir)
0 0 1 0	->  look(dir)
0 0 0 1	->  pos	(pos)
```

> 월드 행렬을 구성하는 순서

- 필요에 의해 존재해야 하는 행렬들이 있다면 반드시 곱셈 순서는 지켜야 한다.
- 모두 있어야 하는 필수 요소는 아니다.

- 월드 행렬 = 크기행렬 * 자전 행렬 * 이동 행렬 * 공전 행렬 * 부모(위치) 행렬
- 만약 자전 행렬의 경우 x,y,z축으로 모두 회전하는 경우 모두 행렬을 곱해줘야 한다
ex) 크기 * (x * y * z)

> 각종 행렬을 만들어주는 함수

- 크기 변환 행렬을 만들어주는 함수
```cpp
D3DXMatrixScaling(결과를 저장할 행렬의 주소, x배율, y배율, z배율) 
```
- x축 회전 행렬을 만들어주는 함수
```cpp
D3DXMatrixRotationX(결과를 저장할 행렬의 주소, D3DXToRadian(각도)) // 각도 -> Degree
```
- y축 회전 행렬을 만들어주는 함수
```cpp
D3DXMatrixRotationY(결과를 저장할 행렬의 주소, D3DXToRadian(각도)) // 각도 -> Degree
```
- z축 회전 행렬을 만들어주는 함수
```cpp
D3DXMatrixRotationZ(결과를 저장할 행렬의 주소, D3DXToRadian(각도)) // 각도 -> Degree
```
- 이동 행렬을 만들어주는 함수
```cpp
D3DXMatrixTranslation(결과를 저장할 행렬의 주소, x좌표,y좌표, z좌표)
```
- 항등 행렬을 만들어주는 함수
```cpp
D3DXMatrixIdentity(결과를 저장할 행렬의 주소)
```
- 행렬 곱셈을 수행시키는 함수
```cpp
D3DXVec3TransformCoord(결과 값(위치)을 저장할 벡터의 주소, 행렬과 곱셈을 수행할 위치 벡터의 주소, 곱셈을 수행할 행렬의 주소)
D3DXVec3TransformNormal(결과 값(방향)을 저장할 벡터의 주소, 행렬과 곱셈을 수행할 방향 벡터의 주소, 곱셈을 수행할 행렬의 주소)
```

</details>
