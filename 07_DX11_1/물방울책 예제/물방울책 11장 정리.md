# DX11 공부 정리(물방울책) - 11장

### Chapter10. 기하 셰이더 - 빌보드

<details>
  <summary> 0. 기하셰이더란 </summary>

- 기하셰이더는 레스터라이저 단계와 버텍스 셰이더 단계 사이에 있는 렌더링 파이프라인 단계이다.
- 버텍스 셰이더는 정점 하나를 입력받고 정점 하나를 반환하지만 기하셰이더에서는 정점 하나를 입력 받고 여러 정점을 내보낼 수 있다.
- 출력이 바로 래스터라이저로 가야하므로 위치는 동차 클립 공간이어야 함. (투영 행렬까지 곱한 결과이어야 함)

</details>

<details>
  <summary> 1. 기하 셰이더의 구조 </summary>

```hlsl
[maxvertexcount(4)]
void GS(point VertexOut gin[1],
        inout TriangleStream<GeoOut> triStream)
{
    GeoOut v;
    // ... v 채우기
    triStream.Append(v);
}
```

> 입력 한정자 `point VertexOut gin[1]`

- 입력 배열의 크기는 프리미티브 종류에 따라 정해진다.

| 한정자 | 정점 수 |
|---|---|
| `point` | 1 | 
| `line` | 2 | 
| `triangle` | 3 |
| `lineadj` | 4 | 
| `triangleadj` | 6 | 

> 출력 스트림 `inout TriangleStream<GeoOut> triStream`

- `PointStream`, `LineStream`, `TriangleStream` 중 하나이고, `Append()`로 정점을 추가할 수 있다.
- 출력은 항상 스트립(띠 형태)로 나감. 리스트 처럼 끊으려면 `RestartStrip()`을 호출해야 함.

> `maxvertexcount`

- 한 번 호출에서 내보낼 최대 정점 수이며 반드시 지정해야 합니다. 성능상 작을수록 좋습니다.

> 입출력 타입

- 입력 정점 타입과 출력 정점 타입은 달라도 된다.
- 입력이 점이고 출력이 삼각형이어도 된다.
  
</details>

<details>
  <summary> 2. 나무 빌보드 </summary>

> 개요

- 멀리있는 나무는 메시 대신 항상 카메라를 향하는 사각형(빌보드)에 텍스처를 입혀 그린다.
- CPU에서는 나무 하나당 점 하나만 보내고, 기하 셰이더가 점을 사각형으로 확장한다.
- 나무가 눕지 않도록 y축은 고정하고 xz 평면에서만 카메라를 향하게 한다.

> 정점 구조체

- 월드 공간 중심 위치 Pos와 빌보드 사각형의 크기 Size만 가진다.
```cpp
typedef struct tagTreePointSprite
{
	float3_t	vPos;
	float2_t	Size;

	static constexpr uint32_t iNumElements = 2;
	static constexpr D3D11_INPUT_ELEMENT_DESC Elements[iNumElements] =
	{
		{ "POSITION", 0, DXGI_FORMAT_R32G32B32_FLOAT, 0,  0, D3D11_INPUT_PER_VERTEX_DATA, 0 },
		{ "SIZE",     0, DXGI_FORMAT_R32G32_FLOAT,    0, 12, D3D11_INPUT_PER_VERTEX_DATA, 0 },
	};
}TREEPOINTSPRITE;
```
