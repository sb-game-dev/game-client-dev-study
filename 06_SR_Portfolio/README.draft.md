팀 프로젝트로 진행했으며, 아래 항목을 담당했습니다.

**플레이어 · 물리**
- 힘(Force) 기반 주행 — 가속, 마찰, 최고 속도 클램프
- 드리프트와 순간 · 롱 부스터
- 중력 적용과 경사로 주행 처리

**충돌**
- OBB / 구 콜라이더와 레이어 마스크 기반 필터링
- 스플라인 지형 · 벽에 대한 레이캐스트 충돌

**카메라**
- 추격 카메라 보간 처리
- 리플레이용 트랙 카메라 자동 전환
- 뷰 / 투영 행렬 직접 구현

**아이템 시스템**
- 바나나, 번개, 먹구름(시야 방해)
- 아이템 슬롯 2칸 구조와 부스터 게이지
- (미사일 · 물파리 · 물폭탄은 팀원 담당, 카트 측 연동을 맡았습니다)

**연출 · 이펙트**
- 파티클 시스템 (연기 · 착지 먼지 · 드리프트 스파크 · 별)
- 스키드마크, 부스터 젯 · 윈드, 스피드라인
- 렌더 타겟 누적 방식의 화면 블러

**UI**
- HUD (속도, 부스터 게이지, 랩, 타이머)
- 아이템 슬롯, 스타트 · 엔드 카운트다운
- 미니맵

## 구현 상세

### 경사로 주행과 중력

트랙이 하이트맵이 아니라 **스플라인으로 생성된 메시**여서, 높이를 조회할 격자가 없었습니다. 그래서 매 물리 스텝마다 지형을 직접 찾아야 했습니다.

**지형 높이 구하기**
1. 카트의 OBB를 트랙의 **로컬 스페이스로 역변환** (역행렬 + 역쿼터니언)
2. 트랙 BoundingBox와 1차 판정 — 통과한 트랙만 다음 단계로
3. 카트 중심에서 아래로 레이를 쏴 `D3DXIntersectTri`로 삼각형 하나를 찾음
4. 그 삼각형의 평면 방정식으로 지면 y를 계산하고 다시 월드 좌표로 복원

법선은 **역행렬의 전치**로 변환했습니다. 트랙에 스케일이 들어가면 일반 변환으로는 법선이 틀어지기 때문입니다.

**뜨거나 파묻히는 문제**

지면과의 높이 차가 0.09 이하일 때만 지면에 스냅하고, 그보다 벌어지면 공중(AIR) 상태로 전환했습니다. 착지 판정은 0.1로 두어 경계에서 상태가 진동하지 않게 했습니다.

**경사면에서의 카트 회전**

카트의 Up 벡터와 지형 법선 사이의 회전을 쿼터니언으로 만들어 적용했는데, 평지와 경사의 경계에서 카트가 미세하게 떨리는 문제가 있었습니다. 법선이 완전한 수직(`normal.y ≈ 1`)인 프레임이 **3프레임 연속으로 유지될 때만** 회전을 초기화하도록 히스테리시스를 두어 해결했습니다.

**중력 분해**

지면에 붙어 있을 때 중력을 그대로 적용하면 경사면을 파고들었습니다. 중력을 **평면의 -Look 성분으로 투영**해서 경사를 따라 내려가는 가속만 받도록 분해했습니다.

```
지면의 Right = 지형 법선 × 카트 Up
지면의 Look  = Right × 지형 법선
받을 힘      = (-Look · 중력) × (-Look)
```

공중 상태에서는 중력을 전부 적용합니다. 공중에 0.3초 이상 떠 있다가 착지하면 먼지 파티클을 재생해 착지감을 살렸습니다.

### 충돌 처리

**충돌 방식 선택**

카트가 경사면에서 기울기 때문에 AABB로는 판정이 부정확했습니다. 카트 본체는 `DirectX::BoundingOrientedBox`(OBB)를 쓰고, 회전이 판정에 영향을 주지 않는 아이템과 바퀴는 구 충돌을 사용했습니다.

**대상별 처리 차이**

| 대상 | 처리 |
|---|---|
| 카트 ↔ 카트 | OBB 교차 후 SAT 투영으로 MTV를 구해 밀어냄 |
| 카트 ↔ 아이템 | 트리거로 등록해 `TriggerEnter`로 이벤트만 전달 |
| 카트 ↔ 지형 · 벽 | 콜라이더가 아닌 **스플라인 메시 자체**와 판정 |

지형과 벽은 콜라이더를 붙이기엔 형태가 복잡해서, BoundingBox로 광역 판정을 하고 통과한 것만 삼각형 단위로 정밀 판정하는 2단계 구조로 만들었습니다.

**부하를 줄인 방법**

- Unity의 레이어 방식을 참고해 32비트 **레이어 마스크**를 도입, 검사 대상 자체를 비트 연산으로 걸러냄
- 광역(BoundingBox) → 정밀(삼각형) 2단계 판정
- 프레임당 이동을 **2회 서브스텝**으로 나눠 매 스텝 지형 · 벽을 검사 — 고속 주행 시 벽을 뚫고 나가는 터널링을 줄였습니다

### 카메라

`CCameraMgr`가 상태별 카메라를 보유하고, 메인 카메라의 뷰 / 투영 행렬만 갱신하는 구조로 나눴습니다. 뷰 · 투영 행렬은 D3DX 함수를 쓰지 않고 직접 구현했습니다.

**추격 카메라 보간**

목표 위치를 `플레이어 Pos + Up × 8.5 + (-Look) × 15`로 잡고, 현재 위치에서 목표까지의 **거리에 비례한 속도**로 따라가게 했습니다. 고정된 위치에 붙이면 코너에서 화면이 뻣뻣해지는데, 거리 비례로 두면 급코너에서 카메라가 자연스럽게 밀립니다. 후진 중일 때는 계수를 높여(6 → 8) 더 빠르게 따라붙게 했습니다.

카메라의 Up을 플레이어의 Up으로 두어 경사면에서 화면이 함께 기울어지도록 했습니다.

**상황별 연출**

- 출발: StartCam으로 트랙을 비추다가 카운트다운 종료 시 추격 카메라로 전환
- 결승선 통과: FinishCam으로 자동 전환
- 리플레이(Tab): 트랙에 배치된 카메라 중 **카트와 가장 가까운 카메라를 매 프레임 선택** — 중계 화면처럼 보이게 했습니다

### 아이템 시스템

슬롯 2칸을 두고 Alt로 교체, Z로 버릴 수 있게 했습니다. 아이템은 사용 방식에 따라 두 갈래로 나눴습니다.

**조준형 / 비조준형**

- 조준형(미사일, 자석): Ctrl을 **누르고 있는 동안** 조준 오브젝트를 생성해 타겟을 추적하고, 떼는 순간 발사
- 비조준형(그 외): KeyDown 즉시 사용

**화면을 가리는 아이템 vs 상태를 바꾸는 아이템**

먹구름 · 물파리처럼 시야만 막는 아이템은 UI 텍스처를 덮는 것으로 끝나서 주행 로직을 건드리지 않습니다.

반면 번개 · 물폭탄 · 바나나처럼 조작을 막아야 하는 아이템은 카트에 상태 플래그를 세우고, `KeyInput` 진입부에서 한 번에 차단했습니다. 아이템이 늘어날 때마다 조작 코드를 고치지 않아도 되도록 상태 판정을 한 곳에 모았습니다.

**물방울 탈출**

시간 기반 포물선 운동으로 처리했습니다. 1초간 상승 → 0.5초 정지 → 1초 하강 후 자동 해제되며, 그동안 탈출 UI가 표시됩니다.

### 파티클과 이펙트

**생성과 반환**

`PSystem` 추상 클래스에 동적 버텍스 버퍼를 두고, batch / offset을 순환하며 Lock(DISCARD → NOOVERWRITE)해 매 프레임 버퍼 전체를 다시 만들지 않도록 했습니다.

수명이 다한 파티클은 **삭제하지 않고 `ResetParticle`로 초기 상태로 되돌려 재사용**합니다. 주행 중 연기 · 스파크가 계속 생성되는 구조라 매번 할당 / 해제하면 비용이 컸습니다.

파생 파티클: 연기, 착지 먼지, 드리프트 스파크, 별(충돌), 아이템 획득

**RcTex 기반 이펙트**

판형 이펙트는 `CRcTex` 빌보드에 텍스처 프레임 애니메이션을 입혀 표현했습니다. 부스터 젯 · 윈드, 스피드라인, 먹구름이 여기에 해당합니다.

**동시에 많은 이펙트가 나올 때**

- 렌더 그룹을 `SKID / TRAIL / PARTICLE / ALPHA`로 분리해 알파 정렬과 렌더 스테이트 전환을 최소화
- 거리 컬링 + 프러스텀 컬링으로 화면 밖 오브젝트 제외

**화면 블러**

셰이더 없이, 렌더 타겟 2장을 두고 **이전 프레임을 알파로 덮어 누적**하는 방식으로 모션 블러를 만들었습니다. 블러 세기는 속도 60을 넘는 만큼 비례해 0 ~ 0.85 범위로 조절되어, 부스터를 쓸 때 속도감이 강해집니다.

### 미니맵과 UI

**미니맵**

월드 좌표를 2D로 변환하는 대신, 별도 렌더 타겟에 그리면서 **뷰 행렬을 톱뷰로 교체**했다가 원래 뷰로 복원하는 방식을 썼습니다. 카메라의 Look 방향을 기준으로 톱뷰를 잡아, 미니맵이 플레이어 진행 방향에 맞춰 회전합니다. 카트 아이콘은 월드 쿼터니언을 그대로 적용해 방향을 표시합니다.

**순위 표시**

트랙 그래프에 각 카트의 위치를 투영해 얻은 진행도로 정렬하고, `CRankMgr`가 순위 UI 행을 교체합니다.

**HUD 게이지**

속도 · 부스터 게이지는 텍스처의 UV와 스케일을 조절해 채워지는 표현을 만들었고, 숫자는 스프라이트를 자릿수별로 조합해 출력했습니다.

## 조작 방법

| 키 | 동작 |
|---|---|
| ↑ / ↓ | 가속 / 감속 |
| ← / → | 좌 / 우 조향 |
| Left Shift + ← / → | 드리프트 |
| Left Ctrl | 아이템 사용 (조준형은 누른 채 조준 → 떼면 발사) |
| Left Alt | 아이템 슬롯 교체 |
| Z | 첫 번째 슬롯 버리기 |
| Tab | 리플레이 카메라 전환 |

출발 카운트다운이 끝나는 타이밍에 ↑를 누르면 순간 부스터가 발동합니다.

```

```

## 실행 방법

**필요 환경**
- Visual Studio 2022 (플랫폼 도구 집합 v143)
- DirectX SDK (June 2010) — `d3dx9` 사용

**빌드**
1. `Game/Game.sln`을 열고 구성을 **x64 / Release**로 설정
2. 빌드하면 빌드 이벤트가 `Resource`와 `fmod`를 출력 폴더로 복사합니다
3. `Game/Client/Bin/Client.exe` 실행
