# C++ 자료구조 정리

### 1. forward_list
<details>
  <summary>구조적인 특징</summary>

> 기본 구조

`[데이터 | 다음 노드 주소]`

- 자기 데이터를 하나 들고있고
- 다음 노드를 가리키는 포인터 하나만 있음
- 이전 노드의 주소가 없음 그래서 이전 노드로는 못 돌아감(단 방향)
- 따라서 **after 중심 설계**
- instert(pos,value)가 가능하려면 pos 이전 노드를 찾아야 하는데 불가능함
- 따라서 inster_after()를 사용하여 어쩔 수 없이 현재 노드 기준으로 다음만 조작하는 방식(after)’으로 설계를 강제한 것

> 핵심 특징

- 단방향 연결 리스트
next만 있고 prev는 없음
- 메모리 비연속 구조
배열과 달리 흩어져 있음
- 삽입/삭제 빠름(O(1))
특정 위치 **"이후"**에 바로 삽입 가능
- 탐색 느림(O(n))
랜덤 접근이 안되기 때문에 iterator를 통해 처음부터 탐색해야 함
- iterator는 forward만 가능
++it 는 가능하지만 --it 는 안됨
- size() 없음!
랜덤 접근이 불가능하기 때문에 필요하면 직접 카운트 해야 함.
- insert(), erase()가 아니라
inster_after() , erase_after() 사용
</details>

<details>
  <summary>iterator 특징</summary>

```cpp
forward_list<int> f1 = {1,2,3};
for(auto it = f1.begin();it!=f1.end();++it)
{
  cout<< *it <<endl;
}
```
- befor_begin() -> 첫 번째 노드 이전 위치
- begin()  ->  첫 번째 노드
- end()    ->  마지막 노드 다음 위치
- `--it` 불가능(뒤로 못감)
</details>

<details>
  <summary>before_begin()</summary>

> 1. 정의
```cpp
f1.before_begin()
```
- 첫번재 요소 이전 위치를 가리키는 **iterator**
- 실제 노드가 아님
- 메모리상에 존재하지 않음
- 단순히 논리적인 위치를 표현하는 iterator

> 2. 필요한 이유

```cpp
head -> A -> B -> C ->nullptr
```
- forward_list는 위와 같은 구조로 되어있음
- A 앞에 삽입 할 때 f1.push_front(10); 이렇게는 가능하지만
- f1.insert_after(???,10); 이 코드가 힘듬
- 맨 앞 이전 노드를 알아야 하기 때문임
- 따라서 STL이 구조를 다음과 같이 만들어 둠
```cpp
before_begin() -> A -> B -> C -> nullptr
```

> 3. 핵심 역할

- **삽입 기준점 역할**
- forward_list는 모든 삽입이 이렇게 이루어짐:
```
f1.insert_after(it,값); //it 다음에 값 삽입
f1.erase_after(it);     //it 다음 노드 삭제
```
- 이때 첫 노드 이전 위치가 없기 때문에 before_begin() 사용함
</details>

<details>
  <summary>자주 사용하는 함수</summary>

> 1. 삽입
```cpp
f1.push_front(10); //맨 앞에 10 추가
```
```cpp
f1.insert_after(it,10) // it 다음 위치에 10 추가
```
> 2. 삭제
```cpp
f1.pop_front() //맨 앞 삭제
```
```cpp
f1.erase_after(it) // it 다음 노드 삭제
```
> 3. 탐색
```cpp
cout << f1.front() // 첫 번째 값 출력
f1.front() = 30    // front()는 L-value임(내부적으로 참조 반환 int& front())
```
```cpp
for(auto it = f1.begin();it!=f1.end();++it)
{
  cout<<
}
```
> 4. 기타
```cpp
f1.empty()    // 비어있는지 확인
f1.clear()    // 전체 삭제
f1.remove(값) // 특정 값 모두 제거
f1.sort()     // 정렬
f1.reverse()  // 뒤집기
```
</details>
