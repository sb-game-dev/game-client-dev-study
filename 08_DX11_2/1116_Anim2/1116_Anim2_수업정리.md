# 1116_Anim2 총정리 — 키프레임 애니메이션 재생 (Animation → Channel → Bone)

> 1113_Skinned → 1116_Anim2 비교. 이번에는 **Engine만** 바뀌었고 Client는 그대로다.

| 구분 | 파일 |
|---|---|
| Engine 새 파일 | `Animation.h/.cpp`, `Channel.h/.cpp` |
| Engine 수정 | `Engine_Struct.h`(KEYFRAME), `Bone.h`(Set_TransformationMatrix), `Model.h/.cpp` |
| 프로젝트 | `Engine.vcxproj(.filters)`에 새 파일 4개 등록 |
| SDK 복사 | `EngineSDK/Inc`에 `Animation.h`, `Channel.h`가 새로 생기고 `Bone.h`, `Engine_Struct.h`, `Model.h`가 갱신됨 |

1113에서는 `Play_Animation()`의 **1단계(뼈의 TransformationMatrix를 애니메이션에 맞게 세팅)** 를 주석으로만 남겨 두었다. 이번 수업은 그 빈자리를 채운다.
- FBX의 애니메이션 데이터를 `CAnimation`(애니메이션 1개)과 `CChannel`(그 안에서 뼈 1개의 키프레임 목록)로 옮긴다.
- 매 프레임 재생 위치를 진행시킨다.
- 앞뒤 키프레임을 보간해 뼈의 로컬 행렬을 덮어쓴다.
- Client의 `Monster.cpp`는 이미 `Play_Animation(fTimeDelta)`를 호출하고 있다. 그래서 **Client를 수정하지 않아도 모델이 움직이기 시작한다.**

---

## 1. 오늘의 구조

### Assimp 데이터 ↔ 엔진 클래스 대응

```
aiScene
 └ mAnimations[]            → CModel::m_Animations      (vector<CAnimation>)
     aiAnimation            → CAnimation                (이름, 길이, 속도)
      └ mChannels[]         → CAnimation::m_Channels    (vector<CChannel>)
          aiNodeAnim        → CChannel                  (뼈 하나의 키 목록)
           ├ mScalingKeys[]  ┐
           ├ mRotationKeys[] ├→ CChannel::m_KeyFrames   (vector<KEYFRAME>)
           └ mPositionKeys[] ┘
```

| 클래스 | 무엇을 보관하나 | 핵심 함수 |
|---|---|---|
| `CAnimation` | 애니메이션 1개의 이름, 전체 길이(Duration), 초당 Tick 수, 현재 재생 위치, 채널 목록 | 재생 위치를 진행시키고 모든 채널에 전달 |
| `CChannel` | 이 애니메이션에서 **움직이는 뼈 1개**의 키프레임 목록, 그 뼈의 인덱스, 현재 왼쪽 키 인덱스 | 재생 위치로 키 사이를 보간해서 뼈 행렬 세팅 |
| `KEYFRAME` | 특정 시점(Tick)의 Scale / Rotation(쿼터니언) / Position | - |

> 모델의 **모든 뼈가 채널을 갖는 것은 아니다.** 해당 애니메이션에서 움직이는 뼈만 채널이 있다.

### 시간 단위: Tick
- `mDuration`과 키의 `mTime`은 **초가 아니라 Tick** 단위다.
- `mTicksPerSecond`는 1초에 몇 Tick이 진행되는지, 즉 재생 속도다.
- 그래서 매 프레임 `재생위치 += TickPerSecond × fTimeDelta`로 초를 Tick으로 바꿔서 누적한다.

### 매 프레임 호출 흐름

```
CMonster::Update
 └ CModel::Play_Animation(dt)
    ├ [1단계 - 오늘] CAnimation::Update_TransformationMatrix(Bones, dt)    // dt → Tick 누적
    │    └ (채널마다) CChannel::Update_TransformationMatrix(Bones, TrackPos)
    │         └ 키프레임 보간 → CBone::Set_TransformationMatrix(SRT 행렬)
    └ [2단계 - 1113] (뼈마다) CBone::Update_CombinedTransformationMatrix   // 부모 Combined 곱
         └ Bind_BoneMatrices → 셰이더에서 스키닝
```

## 2. 수업 진행 순서대로 코드 따라가기

로딩 쪽은 Assimp 구조를 **위에서 아래로** 따라 내려간다 (Model → Animation → Channel → KeyFrame). 아래 클래스가 준비되면 다시 위로 올라와 연결한다. 매 프레임 갱신도 같은 경로로 내려간다.

### STEP 1. CModel — 애니메이션을 담을 그릇

**Model.h에 추가된 멤버**
```cpp
uint32_t								m_iNumAnimations = {};
vector<shared_ptr<class CAnimation>>	m_Animations;
uint32_t								m_iCurrentAnimIndex = {};
```
- `m_iNumAnimations`: FBX 하나에 들어 있는 애니메이션 개수다 (Idle, Run, Attack …).
- `m_Animations`: 애니메이션 객체 목록이다. `class CAnimation` 전방 선언으로 헤더끼리 include하지 않아도 된다.
- `m_iCurrentAnimIndex`: 지금 재생할 애니메이션 번호다. 아직 바꾸는 함수가 없어서 항상 0번만 재생된다.

```cpp
HRESULT Ready_Animations();
```
- 다른 `Ready_*` 함수들과 같은 패턴의 private 초기화 함수다.

**새 함수 `CModel::Ready_Animations()`**
```cpp
HRESULT CModel::Ready_Animations()
{
    m_iNumAnimations = m_pAIScene->mNumAnimations;

    for (uint32_t i = 0; i < m_iNumAnimations; i++)
    {
        auto        pAnimation = CAnimation::Create(m_pAIScene->mAnimations[i] ,this);
        if (nullptr == pAnimation)
            return E_FAIL;

        m_Animations.push_back(pAnimation);       
    }

    return S_OK;
}
```
- **애니메이션 개수**: 씬에서 애니메이션 개수를 가져온다.
- **for문**: `aiAnimation*` 하나당 `CAnimation`을 하나씩 만든다.
- **두 번째 인자 `this`(모델 자신)**: 맨 아래 `CChannel`이 "내 뼈가 모델의 몇 번째 뼈인지"를 `Get_BoneIndex()`로 물어봐야 하기 때문에 넘긴다.
- **실패 처리**: 하나라도 생성에 실패하면 모델 로딩 전체가 실패한다.

**Initialize_Prototype와 복사 생성자**
```cpp
    if (FAILED(Ready_Materials(pModelFilePath)))
        return E_FAIL;

    if (FAILED(Ready_Animations()))
        return E_FAIL;
```
- 채널이 뼈 이름으로 인덱스를 찾으므로 `Ready_Bones`가 **먼저** 끝나 있어야 한다. 이 순서는 지켜져 있다.

```cpp
    , m_iNumAnimations { Prototype.m_iNumAnimations }
    , m_Animations { Prototype.m_Animations }
```
- Clone할 때 원형의 애니메이션 목록을 그대로 복사한다.
- `shared_ptr` 벡터를 복사하는 것이라 **애니메이션 객체 자체는 원형과 공유된다** (4장 참고).

### STEP 2. CAnimation 뼈대 — 기본 정보만 읽기

**Animation.h (전체)**
```cpp
#pragma once

	f32_t				m_fTickPerSecond = {};

	/* 이 애니메이션을 재생위해 필요한 뼈의 갯수 */

```

**클래스 형태**
- `CBone`과 같은 형태다. 컴포넌트가 아닌 일반 클래스이고, 생성자는 private이며 `Create()` 팩토리로만 만든다.
- `ENGINE_DLL`이 없으므로 엔진 내부 전용 클래스다.

**멤버 변수**
- `m_fDuration`: 전체 길이 (Tick)
- `m_fTickPerSecond`: 초당 Tick 수 (재생 속도)
- `m_fCurrentTrackPosition`: 현재 재생 위치 (Tick)
- `m_Channels`: 이 애니메이션에서 움직이는 뼈마다 하나씩 있는 채널 목록

**Initialize — 이 단계에서는 기본 정보까지만 작성**
```cpp
#include "Animation.h"

HRESULT CAnimation::Initialize(const aiAnimation* pAIAnimation, class CModel* pModel)
{
    strcpy_s(m_szName, pAIAnimation->mName.C_Str());
    m_fDuration = pAIAnimation->mDuration;
    m_fTickPerSecond = pAIAnimation->mTicksPerSecond;

    m_iNumChannels = pAIAnimation->mNumChannels;

    return S_OK;
}
```
- **기본 정보**: 이름, 길이, 속도를 읽는다. `mDuration`과 `mTicksPerSecond`는 `double`이라 `float`로 바뀌며 경고가 날 수 있다.
- **채널 개수**: 읽어만 둔다. 채널 하나를 표현할 `CChannel`이 아직 없어서 실제 객체는 STEP 4에서 만든다.
- **`pModel`**: 지금은 쓰지 않는다. 채널에 넘겨주려고 미리 받아 두는 것이다.

### STEP 3. KEYFRAME 구조체 + CChannel ★

**Engine_Struct.h에 추가**
```cpp
typedef struct tagKeyFrame
{
    XMFLOAT3		vScale;
    XMFLOAT4		vRotation;
    XMFLOAT3		vPosition;
    float			fTrackPosition;
}KEYFRAME;
```
- 특정 시점(`fTrackPosition`, Tick)에 뼈가 가질 크기, 회전(쿼터니언이라 4성분), 위치를 담는다.
- **행렬이 아니라 S/R/T로 나눠 저장하는 이유는 보간 때문이다.** 행렬끼리 선형보간하면 결과가 찌그러진다. S와 T는 Lerp로, R은 Slerp로 따로 보간해야 자연스럽다.

**Channel.h (전체)**
```cpp
#pragma once

#include "Engine_Defines.h"

/* 특정애니메이션을 위해 사용되는 뼈의 정보.  */
/* 재생 위치에 따른 상태들을 보관한다. */

NS_BEGIN(Engine)

class CChannel final 
{
private:
	CChannel();
public:
	virtual ~CChannel() = default;

public:
	HRESULT Initialize(const aiNodeAnim* pAIChannel, class CModel* pModel);
	void Update_TransformationMatrix(const vector<shared_ptr<class CBone>>& Bones, f32_t fCurrentTrackPosition);

private:
	char_t				m_szName[MAX_PATH] = {};
	uint32_t			m_iNumKeyFrames = {};
	vector<KEYFRAME>	m_KeyFrames;
	int32_t				m_iBoneIndex = {};
	uint32_t			m_iLeftKeyFrameIndex = { };

public:
	static shared_ptr<CChannel> Create(const aiNodeAnim* pAIChannel, class CModel* pModel);
};

NS_END
```
- `m_szName`: 채널 이름이다. 움직일 뼈의 이름과 같다.
- `m_KeyFrames`: 시간순으로 정렬된 키프레임 목록이다.
- `m_iBoneIndex`: 모델의 `m_Bones`에서 이 채널이 담당하는 뼈의 인덱스다. 매 프레임 이름으로 찾으면 느리므로 초기화 때 **한 번만** 찾아 둔다.
- `m_iLeftKeyFrameIndex`: 현재 재생 위치 바로 왼쪽(이전) 키의 인덱스다. 매 프레임 처음부터 찾지 않도록 기억해 둔다.

**Channel.cpp — Initialize**
```cpp
#include "Channel.h"
#include "Model.h"
#include "Bone.h"

CChannel::CChannel()
{
}

HRESULT CChannel::Initialize(const aiNodeAnim* pAIChannel, class CModel* pModel)
{
    strcpy_s(m_szName, pAIChannel->mNodeName.C_Str());

    m_iBoneIndex = pModel->Get_BoneIndex(m_szName);
    if (-1 == m_iBoneIndex)
        return E_FAIL;

    m_iNumKeyFrames = max(pAIChannel->mNumScalingKeys, pAIChannel->mNumRotationKeys);
    m_iNumKeyFrames = max(m_iNumKeyFrames, pAIChannel->mNumPositionKeys);

    float3_t        vScale{};
    float4_t        vRotation{};
    float3_t        vPosition{};

    for (uint32_t i = 0; i < m_iNumKeyFrames; i++)
    {
        KEYFRAME            KeyFrame{};

        if(i < pAIChannel->mNumScalingKeys)
        {
            KeyFrame.fTrackPosition = pAIChannel->mScalingKeys[i].mTime;
           memcpy(&vScale, &pAIChannel->mScalingKeys[i].mValue, sizeof(float3_t));
        }

        if (i < pAIChannel->mNumRotationKeys)
        {
            KeyFrame.fTrackPosition = pAIChannel->mRotationKeys[i].mTime;
            vRotation.x = pAIChannel->mRotationKeys[i].mValue.x;
            vRotation.y = pAIChannel->mRotationKeys[i].mValue.y;
            vRotation.z = pAIChannel->mRotationKeys[i].mValue.z;
            vRotation.w = pAIChannel->mRotationKeys[i].mValue.w;            
        }

        if (i < pAIChannel->mNumPositionKeys)
        {
            KeyFrame.fTrackPosition = pAIChannel->mPositionKeys[i].mTime;
            memcpy(&vPosition, &pAIChannel->mPositionKeys[i].mValue, sizeof(float3_t));
        }

        KeyFrame.vScale = vScale;
        KeyFrame.vRotation = vRotation;
        KeyFrame.vPosition = vPosition;

        m_KeyFrames.push_back(KeyFrame);
    }

	return S_OK;
}
```

**① 뼈 연결**
- `mNodeName`(움직일 노드 이름)을 1113에서 만든 `CModel::Get_BoneIndex()`로 인덱스로 바꾼다.
- 뼈를 찾지 못하면(-1) 실패 처리한다. 그러면 채널 → 애니메이션 → 모델 로딩까지 연쇄적으로 실패한다.

**② 키프레임 개수**
- Assimp는 Scale, Rotation, Position 키를 **각각 따로, 개수도 다르게** 준다 (예: 회전 키 30개, 크기 키 1개).
- 그래서 셋 중 **가장 많은 개수**를 기준으로 잡는다.

**③ for문 밖에 선언한 `vScale / vRotation / vPosition`**
- 어떤 성분의 키가 먼저 끝나면 해당 `if`에 들어가지 않는다.
- 그래서 그 성분은 **마지막 값을 그대로 유지**한 채 이후 키프레임에 계속 들어간다.

**④ 값 복사**
- Scale과 Position: `aiVector3D`와 `XMFLOAT3`는 메모리 구조(float 3개)가 같으므로 `.mValue`를 `memcpy`한다.
  - 주의: 키 구조체(`aiVectorKey`) 자체는 `{ double mTime; aiVector3D mValue; }`이므로 반드시 **`.mValue`** 에서 복사해야 한다.
- Rotation: `aiQuaternion`은 **w, x, y, z** 순서이고 `XMFLOAT4`는 **x, y, z, w** 순서다. 그래서 memcpy를 쓰지 않고 성분별로 대입한다.

**⑤ fTrackPosition**
- 세 if를 지나며 덮어써지므로 마지막으로 들어간 성분의 시간이 남는다.
- 세 종류 키의 시간이 인덱스별로 서로 맞는다는 전제를 깔고 있다.

### STEP 5. 매 프레임 로직 ★

#### 5-1. CAnimation::Update_TransformationMatrix — 재생 위치 진행
```cpp
void CAnimation::Update_TransformationMatrix(const vector<shared_ptr<class CBone>>& Bones, f32_t fTimeDelta)
{
    /*현재 트랙내에서의 재생위치를 구한다. */
    m_fCurrentTrackPosition += m_fTickPerSecond * fTimeDelta;

    if (m_fCurrentTrackPosition >= m_fDuration)
    {

    }

    for (auto& pChannel : m_Channels)
    {
        pChannel->Update_TransformationMatrix(Bones, m_fCurrentTrackPosition);
    }


}

shared_ptr<CAnimation> CAnimation::Create(const aiAnimation* pAIAnimation, class CModel* pModel)
{
    auto pInstance = shared_ptr<CAnimation>(new CAnimation());

    if (FAILED(pInstance->Initialize(pAIAnimation, pModel)))
    {
        MSG_BOX("Failed to Created : CAnimation");
        pInstance.reset();
    }

    return pInstance;
}
```
- **재생 위치 진행**: `TickPerSecond × TimeDelta`는 이번 프레임에 흐른 Tick이다. 이 값을 누적한다.
- **비어 있는 if**: 끝에 도달했을 때(루프 또는 종료) 처리할 자리만 만들어 둔 상태다. 아직 비어 있어서 **한 번 재생한 뒤 마지막 자세에서 멈춘다.**
- **채널 순회**: 계산한 재생 위치를 모든 채널에 넘긴다.
- **Create**: 다른 클래스와 같은 팩토리 패턴이다.

#### 5-2. CChannel::Update_TransformationMatrix — 키프레임 보간
```cpp
void CChannel::Update_TransformationMatrix(const vector<shared_ptr<class CBone>>& Bones, f32_t fCurrentTrackPosition)
{
    vector_t        vScale{}, vRotation{}, vTranslation{};

    KEYFRAME        LastKeyFrame = m_KeyFrames.back();

    if (fCurrentTrackPosition >= LastKeyFrame.fTrackPosition)
    {
        vScale = XMLoadFloat3(&LastKeyFrame.vScale);
        vRotation = XMLoadFloat4(&LastKeyFrame.vRotation);
        vTranslation = XMVectorSetW(XMLoadFloat3(&LastKeyFrame.vPosition), 1.f);
    }
    else /* 선형보간이 필요한 경우 */
    {
        if (fCurrentTrackPosition >= m_KeyFrames[m_iLeftKeyFrameIndex + 1].fTrackPosition)
            ++m_iLeftKeyFrameIndex;  

        f32_t       fRatio = (fCurrentTrackPosition - m_KeyFrames[m_iLeftKeyFrameIndex].fTrackPosition) / 
            (m_KeyFrames[m_iLeftKeyFrameIndex + 1].fTrackPosition - m_KeyFrames[m_iLeftKeyFrameIndex].fTrackPosition);

        vector_t    vLeftScale, vRightScale;
        vector_t    vLeftRot, vRightRot;
        vector_t    vLeftPos, vRightPos;

        vLeftScale = XMLoadFloat3(&m_KeyFrames[m_iLeftKeyFrameIndex].vScale);
        vLeftRot = XMLoadFloat4(&m_KeyFrames[m_iLeftKeyFrameIndex].vRotation);
        vLeftPos = XMVectorSetW(XMLoadFloat3(&m_KeyFrames[m_iLeftKeyFrameIndex].vPosition), 1.f);

        vRightScale = XMLoadFloat3(&m_KeyFrames[m_iLeftKeyFrameIndex + 1].vScale);
        vRightRot = XMLoadFloat4(&m_KeyFrames[m_iLeftKeyFrameIndex + 1].vRotation);
        vRightPos = XMVectorSetW(XMLoadFloat3(&m_KeyFrames[m_iLeftKeyFrameIndex + 1].vPosition), 1.f);

        vScale = XMVectorLerp(vLeftScale, vRightScale, fRatio);
        vRotation = XMQuaternionSlerp(vLeftRot, vRightRot, fRatio);
        vTranslation = XMVectorLerp(vLeftPos, vRightPos, fRatio);
    }

    Bones[m_iBoneIndex]->Set_TransformationMatrix(
        XMMatrixAffineTransformation(
            vScale, 
            XMVectorSet(0.f, 0.f, 0.f, 1.f), 
            vRotation, 
            vTranslation
        ));
    
}

shared_ptr<CChannel> CChannel::Create(const aiNodeAnim* pAIChannel, class CModel* pModel)
{
    auto pInstance = shared_ptr<CChannel>(new CChannel());

    if (FAILED(pInstance->Initialize(pAIChannel, pModel)))
    {
        MSG_BOX("Failed to Created : CChannel");
        pInstance.reset();
    }

    return pInstance;
}
```

**① 마지막 키 이후**
- 재생 위치가 마지막 키를 지나면 보간할 오른쪽 키가 없다. 그래서 마지막 키 값을 그대로 쓴다.
- `>=`인 덕분에 키가 1개뿐인 채널도 항상 이 분기로 들어간다. 그래서 아래 `+1` 접근이 범위를 벗어나지 않는다.
- 위치는 `XMVectorSetW(..., 1.f)`로 w를 1로 만들어 점으로 다룬다.

**② 보간 구간**
- **왼쪽 키 갱신**: 재생 위치가 다음 키를 넘었으면 `m_iLeftKeyFrameIndex`를 한 칸 앞으로 옮긴다.
- **fRatio** = (현재 위치 − 왼쪽 키 시간) / (오른쪽 키 시간 − 왼쪽 키 시간). 두 키 사이에서 0~1 사이의 진행 비율이다.
- **보간**:

| 성분 | 보간 함수 | 이유 |
|---|---|---|
| Scale | `XMVectorLerp` | 선형보간이면 충분하다 |
| Rotation | `XMQuaternionSlerp` | 쿼터니언을 Lerp하면 길이가 1이 아니게 되고 회전 속도가 고르지 않다. 구면 보간이 필요하다 |
| Position | `XMVectorLerp` | 선형보간이면 충분하다 |

**③ 뼈에 적용**
- `XMMatrixAffineTransformation(스케일, 회전중심(원점), 회전쿼터니언, 이동)`으로 S/R/T를 행렬 하나로 합친다.
- 그 행렬을 담당 뼈의 `TransformationMatrix`(부모 기준 로컬 행렬)로 덮어쓴다.

#### 5-3. CBone::Set_TransformationMatrix
```cpp
void Set_TransformationMatrix(fmatrix_t TransformationMatrix) {
    XMStoreFloat4x4(&m_TransformationMatrix, TransformationMatrix);
}
```
- 채널이 계산한 SIMD 행렬을 멤버 저장용 `float4x4_t`로 저장한다.
- 1113까지 `m_TransformationMatrix`는 `aiNode`에서 읽은 **바인드 포즈**였다. 이제는 **매 프레임 애니메이션 값으로 덮어써진다.**

### STEP 6. Play_Animation 연결

```cpp
void CModel::Play_Animation(f32_t fTimeDelta)
{
    /* 1.뼈들의 TrnasformationMatrix행렬을 현재 애니메이션에 맞게 셋팅한다. */
    m_Animations[m_iCurrentAnimIndex]->Update_TransformationMatrix(m_Bones, fTimeDelta);

    /* 2.TrnasformationMatrix와 부모의 CombinedMatrix를 곱해서 나의 Combined를 만든다. */
    for (auto& pBone : m_Bones)
        pBone->Update_CombinedTransformationMatrix(m_Bones, XMLoadFloat4x4(&m_PreTransformMatrix));
}
```
- 오늘 새로 들어간 코드는 **1단계 한 줄**이다. 이 한 줄로 Animation → Channel → Bone 흐름 전체가 실행된다.
- 2단계는 1113 코드 그대로다. 새 로컬 행렬에 부모의 Combined를 곱한다.
- 그 결과가 `Bind_BoneMatrices`를 거쳐 셰이더 스키닝에 쓰인다.

## 3. 핵심 포인트 모음

- **로컬 행렬만 바꾸면 된다**: 애니메이션은 뼈의 `TransformationMatrix`(부모 기준)만 덮어쓴다. 누적(Combined) → `Offset × Combined` → 셰이더로 이어지는 과정은 1113에서 만든 그대로 동작한다.
- **S/R/T로 분리해서 보간한다**: 행렬은 직접 보간하지 않는다. 회전만 Slerp를 쓴다.
- **시간 단위는 Tick이다**: `TickPerSecond × dt`로 초를 Tick으로 바꿔 누적한다.
- **채널 = 움직이는 뼈**: 채널은 이름으로 뼈 인덱스를 **로드할 때 한 번만** 찾아 둔다.
- **키 개수가 성분마다 다르다**: 가장 많은 개수에 맞추고, 부족한 성분은 마지막 값을 유지한다.
- **쿼터니언 성분 순서**: `aiQuaternion`(w,x,y,z) ≠ `XMFLOAT4`(x,y,z,w). memcpy로 복사하면 안 된다.
- **`aiVectorKey`에서 값 꺼내기**: 반드시 `.mValue`에서 복사한다. 구조체 앞부분은 `double mTime`이다.
- **로드 순서**: 채널이 뼈 이름을 찾으므로 `Ready_Bones`가 `Ready_Animations`보다 먼저 와야 한다.

## 4. 알려진 한계 / 다음에 손볼 곳

1. **루프가 비어 있음**: `CAnimation::Update`의 `if (>= Duration)`이 비어 있다. 끝까지 재생하면 마지막 자세에서 멈춘다.
   - 루프를 만들 때는 재생 위치를 0(또는 `-= Duration`)으로 되돌리는 것만으로는 부족하다. **각 채널의 `m_iLeftKeyFrameIndex`도 0으로 되돌려야 한다.**
   - 되돌리지 않으면 두 번째 바퀴부터 `fRatio`가 음수가 되어 자세가 깨진다.
   - 확실한 방법은 채널에서 "재생 위치 < 왼쪽 키 시간"이면 인덱스를 0으로 되돌리는 것이다.
2. **키를 한 칸씩만 넘김**: 왼쪽 키 갱신이 `if`라서 프레임이 크게 튀면 따라가지 못한다. `while`로 바꾸는 편이 안전하다.
3. **애니메이션 상태를 클론끼리 공유**: 복사 생성자가 `m_Animations`와 `m_Bones`를 `shared_ptr`로 얕게 복사한다. 같은 모델을 쓰는 객체가 여러 개면 재생 위치와 키 인덱스를 공유해서 재생이 빨라지거나 꼬인다. 클론마다 깊은 복사(Clone)가 필요하다.
4. **애니메이션 전환 없음**: `m_iCurrentAnimIndex`를 바꾸는 함수(`Set_Animation` 등)가 없다.
5. **애니메이션 사이 블렌딩 없음**: 애니메이션을 전환하면 자세가 바로 바뀐다. 이전 자세와 섞는 처리는 아직 없다.
